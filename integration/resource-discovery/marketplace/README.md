# Marketplace

Provides a governed commercial exchange environment where providers publish resources — datasets, applications, and services — with pricing models, licensing terms, and usage conditions, and where consumers discover, compare, and procure offerings. It supports the full acquisition journey: browsing and filtering a federated catalogue of offerings across providers; evaluating terms, pricing, and compliance certifications; initiating procurement or subscription workflows; and managing active entitlements and renewals. The marketplace layer adds commercial and governance context above the technical resource catalogue, enabling trusted exchange within and across data space ecosystems.
